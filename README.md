# 배틀로얄 2.0 플러그인

Minecraft 1.20.1 Paper 서버용 배틀로얄 플러그인입니다. TACZ 모드와 함께 사용하도록 설계되었습니다.

## 📋 주요 기능

### 🎮 게임 시스템
- **포인트 시스템**: 시작 1000점, 킬 보상 및 사망 패널티
- **현상금 시스템**: 5분 후 활성화, 3분마다 슬롯머신 연출로 교체
- **데스타임**: 모든 플레이어가 2번 이상 사망 시 시작, 5분간 진행
- **팀 시스템**: 팀원 수 지정 가능, 같은 팀은 같은 위치 스폰
- **리스폰**: 일반 1분, 데스타임 30초 후 부활

### 🗺️ 맵 시스템
- **커스텀 월드 생성기**: 동굴 없음, 바다 없음, 구조물 없음
- **다양한 바이옴**: 평원, 숲, 자작나무 숲, 짙은 숲, 타이가, 사바나, 산, 초원
- **자연 지형**: 나무, 풀, 꽃 등 자연스러운 장식
- **자기장 시스템**: 3000x3000 시작, 5분마다 1분 동안 600블럭씩 축소
- **건축 제한**: 땅파기 금지, 타워링 금지, 임시 엄폐용만 허용

### 📦 보급품 시스템
- **투하 일정**: 게임 시작 직후 1회, 이후 5분마다 총 3회
- **투하 방식**: 1회당 100초 동안 1초에 1개씩 총 100개
- **루팅 시스템**: TACZ 총기 티어별 확률, 부착물, 탄약, 음식, 장비
- **스마트 나침반**: 나침반이 가장 가까운 보급 상자를 가리키며, 이미 열린 상자는 자동으로 제외

### 📊 UI 시스템
- **스코어보드**: 게임 상태, 경과 시간, 포인트, 사망 횟수, 현상금 정보
- **보스바**: 현상금 대상 및 남은 시간, 보급품 투하 진행률
- **타이틀**: 현상금 선정 슬롯머신 연출

## 🛠️ 빌드 방법

### 필요 사항
- Java 17 이상
- Maven

### 빌드 명령어
```bash
mvn clean package
```

빌드된 JAR 파일은 `target/BattleRoyale2-2.0.0.jar`에 생성됩니다.

## 📥 설치 방법

1. Paper 1.20.1 서버 설치 (또는 Arclight 등 하이브리드 서버)
2. TACZ 모드 설치 (하이브리드 서버 사용 시)
3. `BattleRoyale2-2.0.2.jar`를 `plugins` 폴더에 복사
4. **중요**: 커스텀 월드 생성기를 활성화하려면 다음 설정 필요 (아래 "🗺️ 월드 생성 설정" 참고)
5. 서버 시작

## 🎯 사용 방법

### 명령어
- `/br start <팀원 수>` - 게임 시작 (OP 전용)
  - 예: `/br start 2` - 2:2 팀전
  - 예: `/br start 1` - 개인전
- `/br stop` - 게임 강제 종료 (OP 전용)
- `/br info` - 게임 정보 확인

### 권한
- `battleroyale.admin` - 관리자 명령어 사용 (기본: OP)
- `battleroyale.play` - 게임 참여 (기본: 모두)

## 📖 게임 규칙

### 포인트 시스템
1. **시작 포인트**: 1000점
2. **킬 보상**: 500 + 피해자 포인트 (현상금 대상 2배)
   - 처치자: 50% 즉시 획득
   - 데미지 기여자: 50% 비율 분배
3. **사망 패널티**: 포인트 50% 감소

### 현상금 시스템
- **활성화**: 게임 시작 5분 후
- **지속 시간**: 3분
- **효과**: 공격력 1.5배, 킬 보상 2배
- **선정 연출**: 슬롯머신 애니메이션

### 데스타임
- **시작 조건**: 모든 초기 플레이어가 2번 이상 사망
- **효과**: 모두 현상금 상태, 리스폰 30초
- **종료**: 5분 후 게임 종료, 최종 포인트로 순위 결정

### 건축 규칙
- ✅ **허용**: 달리면서 블럭 설치, 총알 막기용 설치, 엄폐 블럭 파괴
- ❌ **금지**: 땅파기, 타워링 (2블럭 이상 연속 쌓기)

## 🗺️ 월드 생성 설정

### ⚠️ 필수 설정

커스텀 월드 생성기를 사용하려면 **반드시** 다음 단계를 따라야 합니다:

#### 1단계: bukkit.yml 설정

서버 루트 폴더의 `bukkit.yml` 파일을 열고 **맨 아래에** 다음을 추가:

```yaml
worlds:
  world:
    generator: BattleRoyale2:BattleRoyale
  world_nether:
    generator: BattleRoyale2:BattleRoyale
  world_the_end:
    generator: BattleRoyale2:BattleRoyale
```

#### 2단계: 기존 월드 삭제

커스텀 생성기는 **새로 생성되는 월드**에만 적용됩니다. 이미 존재하는 월드에는 적용되지 않으므로:

1. 서버를 **완전히 종료**
2. 다음 폴더들을 **삭제**:
   - `world/`
   - `world_nether/`
   - `world_the_end/`
3. 서버를 다시 시작

#### 3단계: 확인

서버 시작 시 다음 로그가 표시되면 성공:
```
[배틀로얄 2.0] 커스텀 월드 생성기가 등록되었습니다. (바다, 동굴, 구조물 없음)
```

### 🌍 커스텀 월드 특징

생성되는 월드는 다음과 같은 특징을 가집니다:

#### ✅ 생성되는 것
- 🌾 **다양한 바이옴**: 평원, 숲, 자작나무 숲, 짙은 숲, 타이가, 사바나, 산, 초원
- 🌳 **자연 지형**: 나무, 풀, 꽃 등 자연 장식
- ⛰️ **높이 변화**: 60~80 블록 높이의 완만한 언덕

#### ❌ 생성되지 않는 것
- 🌊 **바다 없음**: Ocean 바이옴 완전 제외
- 🕳️ **동굴 없음**: 지하 동굴 시스템 비활성화
- 🏛️ **구조물 없음**: 마을, 사원, 요새, 던전 등 모든 구조물 비활성화
- 👾 **몹 자연 스폰 없음**: 동물/몬스터 자연 스폰 비활성화

## 🐛 알려진 이슈

### TACZ 통합
- TACZ 모드의 NBT 데이터는 실제 TACZ API를 사용하여 설정해야 합니다
- 현재 코드는 기본 구조만 제공하며, TACZ 통합은 추가 작업이 필요합니다

### 월드 생성 문제
- **Arclight/Magma 서버**: `shouldGenerateDecorations()` 활성화 시 StackOverflowError 발생 가능
  - **해결방법**: Paper/Spigot 서버 사용 권장, 또는 장식 생성 비활성화
- **기존 월드**: 커스텀 생성기는 새로 생성되는 월드에만 적용됨
  - **해결방법**: 기존 월드 폴더 삭제 후 재생성

## 📞 지원 및 문제 해결

### 문제가 발생하면 다음을 확인하세요:

1. **서버 버전**: Paper 1.20.1 (권장) 또는 Arclight 1.20.1
2. **Java 버전**: Java 17 이상
3. **TACZ 설치**: 하이브리드 서버에 TACZ 모드 설치 확인
4. **bukkit.yml 설정**: 월드 생성기 설정 확인
5. **월드 삭제**: 기존 월드 폴더 삭제 후 재생성

### 자주 묻는 질문 (FAQ)

**Q: 커스텀 월드가 생성되지 않아요**
- A: `bukkit.yml`에 월드 생성기 설정을 추가했는지 확인하세요
- A: 기존 `world`, `world_nether`, `world_the_end` 폴더를 삭제하고 서버를 재시작하세요

**Q: StackOverflowError가 발생해요**
- A: Arclight/Magma 서버에서 발생할 수 있습니다. Paper/Spigot 사용을 권장합니다
- A: 또는 `BRWorldGenerator.java`에서 `shouldGenerateDecorations()`를 `false`로 변경하세요

**Q: 바다나 동굴이 여전히 생성돼요**
- A: 기존 월드에는 적용되지 않습니다. 월드 폴더를 삭제하고 새로 생성해야 합니다

**Q: 서버 로그에 "Could not set generator" 오류가 나와요**
- A: `plugin.yml`에 `load: STARTUP`이 설정되어 있는지 확인하세요
