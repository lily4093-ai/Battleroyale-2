# 배틀로얄 2.0 플러그인

Minecraft 1.20.1 Paper 서버용 배틀로얄 플러그인입니다. TACZ 모드와 함께 사용하도록 설계되었습니다.

## 📋 주요 기능

### 🎮 게임 시스템
- **포인트 시스템**: 시작 1000점, 킬 보상 및 사망 패널티
- **현상금 시스템**: 5분 후 활성화, 3분마다 슬롯머신 연출로 교체
- **데스타임**: 모든 플레이어가 2번 이상 사망 시 시작, 5분간 진행
- **팀 시스템**: 팀원 수 지정 가능, 같은 팀은 같은 위치 스폰
- **리스폰**: 일반 1분, 데스타임 30초 후 부활

### 🗺️ 맵 시스템
- **커스텀 월드 생성기**: 동굴 없음, 바다 없음 (강은 생성)
- **자기장 시스템**: 3000x3000 시작, 5분마다 1분 동안 600블럭씩 축소
- **건축 제한**: 땅파기 금지, 타워링 금지, 임시 엄폐용만 허용

### 📦 보급품 시스템
- **투하 일정**: 게임 시작 직후 1회, 이후 5분마다 총 3회
- **투하 방식**: 1회당 100초 동안 1초에 1개씩 총 100개
- **루팅 시스템**: TACZ 총기 티어별 확률, 부착물, 탄약, 음식, 장비

### 📊 UI 시스템
- **스코어보드**: 게임 상태, 경과 시간, 포인트, 사망 횟수, 현상금 정보
- **보스바**: 현상금 대상 및 남은 시간, 보급품 투하 진행률
- **타이틀**: 현상금 선정 슬롯머신 연출

## 🛠️ 빌드 방법

### 필요 사항
- Java 17 이상
- Maven

### 빌드 명령어
```bash
mvn clean package
```

빌드된 JAR 파일은 `target/BattleRoyale2-2.0.0.jar`에 생성됩니다.

## 📥 설치 방법

1. Paper 1.20.1 서버 설치
2. TACZ 모드 설치 (Magma 등 하이브리드 서버 사용 시)
3. `BattleRoyale2-2.0.0.jar`를 `plugins` 폴더에 복사
4. 서버 재시작

## 🎯 사용 방법

### 명령어
- `/br start <팀원 수>` - 게임 시작 (OP 전용)
  - 예: `/br start 2` - 2:2 팀전
  - 예: `/br start 1` - 개인전
- `/br stop` - 게임 강제 종료 (OP 전용)
- `/br info` - 게임 정보 확인

### 권한
- `battleroyale.admin` - 관리자 명령어 사용 (기본: OP)
- `battleroyale.play` - 게임 참여 (기본: 모두)

## 📖 게임 규칙

### 포인트 시스템
1. **시작 포인트**: 1000점
2. **킬 보상**: 500 + 피해자 포인트 (현상금 대상 2배)
   - 처치자: 50% 즉시 획득
   - 데미지 기여자: 50% 비율 분배
3. **사망 패널티**: 포인트 50% 감소

### 현상금 시스템
- **활성화**: 게임 시작 5분 후
- **지속 시간**: 3분
- **효과**: 공격력 1.5배, 킬 보상 2배
- **선정 연출**: 슬롯머신 애니메이션

### 데스타임
- **시작 조건**: 모든 초기 플레이어가 2번 이상 사망
- **효과**: 모두 현상금 상태, 리스폰 30초
- **종료**: 5분 후 게임 종료, 최종 포인트로 순위 결정

### 건축 규칙
- ✅ **허용**: 달리면서 블럭 설치, 총알 막기용 설치, 엄폐 블럭 파괴
- ❌ **금지**: 땅파기, 타워링 (2블럭 이상 연속 쌓기)

## 🔧 설정

### 월드 생성
서버의 `bukkit.yml` 또는 `server.properties`에서 월드 생성기를 설정:
```yaml
worlds:
  world:
    generator: BattleRoyale2
```

## 📝 보급품 설정

보급품 내용물은 `SUPPLY_DROP_CONFIG.md`에 정의된 확률과 티어 시스템을 따릅니다:

### 총기 티어
- **Common (50%)**: Glock 17, UZI, M870 등
- **Uncommon (30%)**: SCAR-L, HK416D, AUG 등
- **Rare (15%)**: AK-47, Desert Eagle, M700 등
- **Epic (4%)**: MK14, AI AWP, M249 등
- **Legendary (1%)**: M107, M95, Minigun, RPG-7

### 드롭 확률
- 총기: 35%
- 부착물: 슬롯당 8% (최대 2개)
- 음식: 슬롯당 15% (최대 3개)
- 장비: 슬롯당 10% (최대 2개)
- 조약돌: 25% (16개)
- 탄약: 빈 칸당 6%

## 🐛 알려진 이슈

- TACZ 모드의 NBT 데이터는 실제 TACZ API를 사용하여 설정해야 합니다
